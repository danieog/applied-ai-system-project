# Music Recommender

A music recommendation system with both command-line and web interfaces.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running

### Command Line
```bash
python src/main.py
```

### Web App
```bash
streamlit run src/app.py
```

The web app will open in your browser where you can input your music preferences and get personalized recommendations.
