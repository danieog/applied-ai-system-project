# 🎵 VibeFinder — RAG-Powered Music Recommender

> A content-based music recommender upgraded with Retrieval-Augmented Generation (RAG), combining algorithmic scoring with Claude AI to deliver personalized recommendations and natural language explanations.

---

## Original Project (Module 3)

This project builds on **ai110-module3show-musicrecommendersimulation-starter**, a content-based music recommender simulation built in Module 3 of CodePath AI110. The original system represented songs as structured data (genre, mood, energy, acousticness) and a user taste profile, then scored each song using a weighted formula to surface the best matches. Its goals were to simulate how real-world recommender systems work, expose the role of feature weighting in predictions, and evaluate where rule-based systems succeed and fall short. The original system had no AI language model component — it was a pure algorithmic scorer with a pytest test suite for reliability.
